# Índice de Documentación por Página (`docs/paginas/`)

Este directorio contiene la especificación y documentación técnica completa de cada una de las 21 páginas/rutas del sitio **Envíos DosRuedas**.

Cada documento incluye:

1. **Ruta y metadatos SEO**.
2. **Contexto de Layout Global** (`RootLayout` + `ClientLayout` + Header/Footer).
3. **Componentes específicos importados**.
4. **Estructura jerárquica de secciones y contenido**.
5. **Reglas de negocio y tarifas aplicadas**.
